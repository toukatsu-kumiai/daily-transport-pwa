# 日別輸送実績かんたん入力PWA

個人タクシー事業者向けに、日別輸送実績表および輸送実績報告書PDFをスマホで作成するための簡易PWAです。

紙の記入、手計算、Excelへの転記が苦手な方でも、スマホだけで日々の輸送実績を入力し、月次PDFや支局提出用の輸送実績報告書PDFを作成できることを目的としています。

## 主な機能

- 日別輸送実績の入力
- 走行粁、実車粁、回数、人員、収入などの記録
- 粁収、実車率、合計、平均の自動計算
- 備考欄への「休車」「自使（km）」等の入力
- 月次の日別輸送実績表PDF作成
- 支局提出用の輸送実績報告書PDF作成
- 担当者宛メール作成補助
- バックアップ保存・復元
- スマホ向けPWA対応

## データの保存について

このアプリは、入力データを外部サーバーへ送信しません。

入力データは、利用者自身のスマホまたはブラウザ内のローカル保存領域に保存されます。  
そのため、GitHubや作成者のサーバーに利用者の氏名、営業実績、輸送実績などが保存されることはありません。

ただし、次の場合には保存データが消える可能性があります。

- スマホを初期化した場合
- ブラウザのデータを削除した場合
- キャッシュやサイトデータを削除した場合
- 機種変更した場合
- ブラウザや端末の設定により保存領域が削除された場合

月次PDF作成後および年度終了時には、必ず「バックアップ保存」を行うことをおすすめします。

## バックアップについて

設定画面から「バックアップ保存」を押すと、入力データをJSONファイルとして保存できます。

機種変更やブラウザデータ削除の前には、必ずバックアップを保存してください。  
新しい端末や再設定後は、「バックアップ復元」から保存済みファイルを読み込むことで、続きから利用できます。

## 料金について

このアプリは、静的なHTML、JavaScript、Web App Manifest、Service Workerで構成されています。

現在の版では、外部API、外部データベース、課金サービス、クラウド保存機能などは使用していません。  
そのため、通常利用において利用者にAPI利用料などが発生する仕組みはありません。

ただし、通信料や端末利用料など、利用者自身の通信環境に関する費用は各自の負担となります。
